The Architecture Diagram Blueprint
Create three main columns or sections on your canvas:

Section 1: The Environment (Left Side)
Box 1: Developer (User)

Icon: A person or laptop.

Box 2: GitLab CE v17.8

Icon: GitLab logo.

Sub-components to list inside: Issues, Repositories (.md / .py files), Merge Requests.

Section 2: The AI Agent Backend (Middle)
Box 3: FastAPI Service (The Listener)

Role: Receives incoming webhooks and extracts the JSON data.

Box 4: AI Agent Core Logic (Python)

Role: The main script that manages the workflow (checking context, looping, testing).

Box 5: LiteLLM SDK

Role: The universal translator standardizing your AI prompts.

Section 3: The Enterprise AI Network (Right Side)
Box 6: TDET Proxy Server (Azure AI Foundry)

Role: Secure corporate gateway at http://10.74.6.101:4000/. Handles billing, security, and rate limits.

Box 7: Enterprise Models

Sub-components to list inside: gpt-main (for complex coding/reasoning) and gpt-chat (for simple tasks).

How to draw the Arrows (The Data Flow)
Once your boxes are on the screen, connect them with arrows to show how data moves:

Developer -> GitLab: Draw an arrow labeled "Assigns Issue".

GitLab -> FastAPI: Draw an arrow labeled "Fires Webhook (JSON)".

FastAPI -> Agent Core: Draw an arrow labeled "Extracts Issue Text".

Agent Core -> GitLab: Draw a two-way arrow labeled "REST API: Fetch .md context / files".

Agent Core -> LiteLLM: Draw an arrow labeled "Sends Context + Prompt".

LiteLLM -> TDET Proxy Server: Draw an arrow labeled "Routes standard API call".

TDET Proxy Server -> Enterprise Models: Draw an arrow labeled "Executes 'gpt-main' locally".

Enterprise Models -> Agent Core: Draw an arrow pointing all the way back labeled "Returns Decision (PROCEED or CLARIFY)".

Agent Core -> GitLab: Draw a final arrow pointing back to GitLab labeled "REST API: Post Comment or Create Branch".
